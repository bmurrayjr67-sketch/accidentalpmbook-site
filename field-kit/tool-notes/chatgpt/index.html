Tool notes: ChatGPT

Last checked 23 November 2026, on help.openai.com. ChatGPT changes often. If a button has moved, the help page will have the current steps.

Set it up once: a project

A project in ChatGPT keeps your chats, files and instructions in one place. The instructions you give a project apply only inside that project.

  1. Sign in to ChatGPT.
  2. In the sidebar, choose New project and give it a name, such as “PM work.”
  3. Open the project’s menu (the three dots, top right) and choose Project settings.
  4. Paste the starting instructions below into the instructions box and save.
  5. Start every work chat from inside the project.

Starting instructions

I’m a project manager. In this project, follow these rules every time:

  1. Never make up an owner, a due date, a number or a decision that isn’t in what I gave you. If it’s missing, write “Not stated.”
  2. When you aren’t sure something is right, mark it NOT VERIFIED so I can check it before it goes anywhere.
  3. When I give you a meeting recording or transcript, write the notes in these sections, in this order: Follow-up tasks and requested work (each with an owner and a due date), Risks and open items, Key updates, Decisions, Next steps. If a section is empty, write “None identified.”
  4. Use these correct spellings for names the transcript gets wrong: [name as transcribed → correct name].
  5. Write plainly, for someone who wasn’t in the room. No filler.
  6. You draft. I review and send. Don’t tell me something is ready to send.
  7. Use only what falls inside the window I give you, such as “since Monday.” Don’t carry older items forward unless I’ve marked them to keep.
  8. Before you tell me there’s nothing new on something, look again under its other names and the names of the people involved. If there’s still nothing, say so.
  9. If you couldn’t read a file or something failed, tell me what’s missing. Don’t fill the gap with older information or a guess.
  10. One line per bullet, plain business language, no more than two bullets a section unless there’s a new risk or issue.

Two more instructions I use

Weekly status update. Paste this in a chat with last week’s status and this week’s notes attached.

Update last week’s status from the notes I attach.

  • Use only items from [Monday’s date] on.
  • Update Accomplishments, Upcoming activities, and Risks, issues and decisions.
  • Tag new items NEW. If everything in a section is new, skip the tag.
  • Remove last week’s items unless I’ve marked them with an asterisk.
  • Change timeline dates and status only where the notes give a new date.
  • Don’t change the project summary.
  • Change the date to the following Monday.
  • Leave out anything marked confidential or security-related.

Formatting for OneNote or email. Add this when you want to paste the answer without losing the nested numbering.

Give me the answer as a downloadable HTML file I can paste into OneNote or an email. Use nested numbered lists (1, a, i). Set the font to Calibri 11 pt on every list and list item. No tables, no title, no citations. Group by subject.

After it gives you something

Run it through the Review checklist (worksheet 4) before it goes out. When you catch a mistake it keeps making, add a rule to the instructions and a line to your Checks list (worksheet 3).
